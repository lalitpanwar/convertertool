# 07. Roadmap

Timeline anumaan hai (1 full-stack dev + part-time content/SEO). Team badi ho to tez.

## Phase 0: Validation & setup (Week 1–2)

- [ ] Keyword research (top 100 India keywords) — OpenRush credits refill ya Ahrefs/Semrush/Google Keyword Planner
- [ ] SERP check: top 6 queries par kaun rank karta hai, kaisa content
- [ ] Brand name + domain (`.com` / `.in`), trademark check (iLovePDF jaisa naam **mat** lena)
- [ ] PDF to Word engine benchmark (pdf2docx vs paid API vs LibreOffice) 20 sample files par
- [ ] Licence review (AGPL/GPL libs)
- [ ] Repo, CI/CD, Cloudflare + VPS accounts, Search Console, analytics

**Exit:** keyword list final, PDF to Word ka decision, domain ready.

## Phase 1: MVP (Week 3–8)

- [ ] Design system + ToolShell template + home page
- [ ] Tool registry, sitemap, schema, i18n (en + hi)
- [ ] Wave 1 tools (sab client-side): JPG to PDF, Compress PDF (target KB), Merge, PDF to JPG, Split/Remove/Extract pages. Order: [09](09-tool-priority.md)
- [ ] Server (Gotenberg + API), Word to PDF aur PDF to Word **Wave 2** mein (Phase 2), MVP mein nahi
- [ ] Wave 1 ke problem-query pages ka SEO copy + FAQ (en + hi)
- [ ] 20 use-case pages (compress 100kb etc.)
- [ ] Privacy policy, Terms, About, Contact
- [ ] Core Web Vitals + Lighthouse pass
- [ ] Soft launch, Search Console submit

**Exit:** 5 Wave-1 tools (7 pages) live, indexed, mobile par Lighthouse ≥ 90.

## Phase 2: Growth (Month 3–5)

- [ ] 13 aur tools (split, rotate, watermark, protect, sign, ppt/excel to pdf...)
- [ ] Ads integration (AdSense), CLS safe
- [ ] 10+ guides/blog posts
- [ ] Backlink outreach, Product Hunt
- [ ] Rank tracking, content refresh cycle

**Exit:** 25+ tools, organic traffic trend upar, pehla ad revenue.

## Phase 3: Scale (Month 6–9)

- [ ] OCR, PDF to PPT/Excel, HTML to PDF, Repair, Redact...
- [ ] Indonesian + Portuguese (BR) pages
- [ ] Premium plan (Razorpay + Stripe): bigger files, batch, no ads
- [ ] Drive/Dropbox import

## Phase 4: Differentiate (Month 9+)

- [ ] AI tools (Summarizer, Translate, PDF to Markdown)
- [ ] Edit PDF / Forms
- [ ] API / white-label (optional)
- [ ] Mobile PWA

## Immediate next steps (is hafte)

1. Keyword data lo (credits refill ya Keyword Planner) — sabse zaroori.
2. Brand/domain decide karo.
3. PDF to Word benchmark chalao.
4. Repo init karna (Astro + React + TS + Tailwind) aur ToolShell + JPG to PDF se shuru.

## Risks to schedule

- PDF to Word quality zyada samay le sakti hai -> MVP launch rokna nahi, beta label.
- Content (en + hi, 6 pages) writing ka time andaza kam mat lagao.
